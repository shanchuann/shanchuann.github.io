Create tools 创建工具

工具允许模型通过调用您定义的函数来与外部系统进行交互。工具可以依赖于运行时上下文 ，也可以与代理内存交互。

  • dataclass: Python标准库装饰器，用于自动生成特殊方法（如__init__、__repr__等），简化数据类的创建
  • tool: LangChain框架的装饰器，用于将普通Python函数转换为AI智能体可以调用的工具
  • ToolRuntime: LangChain的工具运行时类，提供工具执行时的上下文访问能力

天气查询工具

@tool装饰器的作用：

  • 将普通函数标记为LangChain工具
  • 自动提取函数的文档字符串和参数信息
  • 使AI模型能够理解工具的功能和用法
  • 在工具调用时提供标准的接口格式

函数参数city: str：

  • 类型注解帮助AI理解需要传入的参数类型
  • 文档字符串”””Get weather for a given city.”””作为工具描述，AI会根据这个描述决定何时调用此工具

返回值：

  • 当前返回硬编码的天气信息
  • 在实际应用中，这里通常会调用真实的天气API（如OpenWeatherMap、和风天气等）
  • 返回格式为字符串，便于AI理解和处理

上下文数据类

@dataclass装饰器的优势：

  • 自动生成构造函数：Context(user_id=”123”)
  • 自动生成清晰的字符串表示
  • 自动实现值比较方法
  • 减少样板代码

上下文的作用：

  • 在不同工具调用间传递用户特定信息
  • 保持对话状态和用户偏好
  • 实现个性化服务的基础
  • 支持多用户场景下的数据隔离

user_id: str字段：

  • 作为用户标识符
  • 可以是数据库ID、会话ID或任何唯一标识
  • 用于检索用户特定的数据或配置

用户位置查询工具

ToolRuntime[Context]参数：

  • 提供类型安全的上下文访问

  • runtime.context包含当前执行的上下文实例

  • 泛型[Context]确保访问正确的上下文类型

Define response format 定义响应格式

可选地，如果你需要代理的响应匹配特定模式，可以定义一个结构化的响应格式。

定义了一个数据类（dataclass）ResponseFormat，用于规范智能体（agent）的响应格式。

  1. @dataclass：这是一个装饰器，它允许我们定义一个数据类。数据类通常用于存储数据，并自动生成特殊方法，如__init__、__repr__等。
  2. class ResponseFormat:：定义了一个名为ResponseFormat的类。
  3. 类文档字符串："""Response schema for the agent.""" 说明了这个类的作用，即作为智能体的响应模式（schema）。
  4. 类属性：
    • punny_response: str：这是一个字符串类型的属性，用于存放带有双关语的响应（punny response）。注释# A punny response (always required)表明这个字段是必须的。
    • weather_conditions: str | None = None：这是一个可选的字符串类型属性，用于存放天气条件信息。它可以是字符串或者None（默认值为None）。注释# Any interesting information about the weather if available说明如果有什么有趣的天气信息，可以放在这里。
