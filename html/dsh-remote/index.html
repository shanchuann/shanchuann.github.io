  1. 01

    给 DSH 装上 Host 插件。

    打开桌面端「插件 → 添加插件 → 安装第三方插件」，输入下方包名，使用 npm 官方源安装。启用后进入「设置 → 远程控制」。

    dsh-remote-harness
  2. 02

    在 Android 上，装好 App。

    前往 GitHub Releases 下载公开的 APK，安装后打开 DSH Remote。支持 Android 8.0 及以上。

    下载 Android APK ↗
  3. 03

    扫一下，继续你的会话。

    同一局域网下，扫描电脑上的配对二维码即可。在外使用时，让手机与电脑加入同一 Tailscale 网络，再扫码连接。

    查看连接说明 ↗

电脑与 DSH 需要保持运行。请在可信局域网内连接，或使用 Tailscale；不要将 Host 端口直接暴露到公网。
