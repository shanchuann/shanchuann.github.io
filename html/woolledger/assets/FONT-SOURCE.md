# 标题字体

Noto Serif SC，700 字重，按本页 h1/h2/h3 和收尾标语字符提取的 Google Fonts 官方字符子集，44,556 字节。自托管为 noto-serif-sc-700.ttf，无运行时字体请求。

原始字体与许可：https://github.com/google/fonts/tree/main/ofl/notoserifsc

官方分发接口：https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@700&display=swap&text=（后接本页标题字符的 URL 编码）

SIL Open Font License 1.1，完整文本见 NotoSerifSC-OFL.txt。子集生成脚本保存在开发工作目录 _preview/woolledger/fetch-font.cjs。修改标题后需补充字符子集；正文保持系统无衬线字体。
